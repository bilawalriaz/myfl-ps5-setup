Jailbreak this PS5

Nothing runs until you press Start. Choose what this boot is for.

Payloads after Relapse

Start

Linux needs the ELF loader alone. When this page finishes, send the loader from your computer while the console is still on:

socat -t 99999999 - TCP:PS5-IP:9021 < ps5-linux-loader.elf

The console enters rest mode by itself. Wait for a solid orange LED, then press power. Do not load kstuff, OnionHEN or etaHEN: the console freezes instead of entering rest mode. Keep the Linux USB SSD in a rear port, with rest-mode USB power set to Always.
