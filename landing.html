DNS entry

In PS5 Settings → Network → Settings → Set Up Internet Connection, select your connected network and open Advanced Settings. Set DNS to Manual, then set both Primary and Secondary DNS to 130.162.174.95. Save and reconnect. Open Settings → User's Guide, Health and Safety, and Other Information → User's Guide.

This redirects both manual hostnames, resolves PlayStation and myfl.uk names, and blocks the known update.playstation.net branch. Other domains are restricted. A general public secondary resolver can bypass interception and blocking. If the internet test fails, try the guide directly; if it also fails, record its exact error and restore DNS to Automatic. Keep system software updates disabled.

Privacy

We count HTTP paths (without query strings), status, bytes and timing, plus aggregate DNS responses. Access logs do not record client IPs, cookies, user agents or DNS query histories. Operational errors may include connection details and are access-restricted. Raw logs are size-capped and rotate; private daily aggregates are kept for seven days. Counts indicate requests, not unique users or successful jailbreaks.
