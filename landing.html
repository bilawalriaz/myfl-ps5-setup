Set up your PS5

For PS5 firmware 13.60. Our prebuilt payload list is ready. You only need your console and an internet connection to start.

Primary & Secondary DNS130.162.174.95
  1. Set DNS to Manual

    Settings → Network → Settings → Set Up Internet Connection. Highlight your connected network, press Options and choose Advanced Settings. Enter the address above in both DNS fields and save.

  2. Open User's Guide

    Settings → User's Guide, Health and Safety, and Other Information → User's Guide. Relapse and the prebuilt payload list start automatically. Leave the page open until startup finishes and check the console notifications before returning home.

Keep automatic system software updates off. After a restart, open User's Guide again; your DNS settings stay saved.

What loads automatically

The setup starts kernel logs, kstuff-lite, ShadowMountPlus and FTP. These provide troubleshooting logs, homebrew patches, home screen registration and file transfer. Apps and app-specific helpers are installed separately.

Use one HEN setup

Do not add etaHEN or onionHEN to this automatic setup, or load them together. If an app needs a different HEN or an HEN-based helper, restart and follow that app's complete setup instructions. Check any saved Payload Manager or autoloader lists for overlapping services before switching.

Full setup and app instructions

Connection trouble?

If the connection test fails, try User's Guide directly. If it also fails, note the error code and return DNS to Automatic. Keep the other network settings unchanged.

Optional tools and downloads

Payload Manager

Open Payload Manager, then Settings → Manage Sources → Add Source. Add https://exploit.myfl.uk/payloads.json. Select myfl.uk PS5 essentials to browse and download the pack. This catalogue is optional. The DNS route already loads its prepared list. For a manual setup, Autoload controls which downloaded payloads start automatically; avoid duplicate services and multiple HENs.

Homescreen entry and downloads

Download the preconfigured autoloader payload folder. Extract ps5_autoloader to the USB root or /data/. Its autoload.txt loads logs, kstuff, ShadowMountPlus and FTP when you open the homescreen app after boot.

  • WebKit Autoloader installer v0.5.2 : send after the first jailbreak, then follow its installation/reboot instructions.
  • Payload Manager v0.5.2 : select payloads using its web interface.
  • kstuff-lite v1.11 : kernel patches for apps that require them, loaded after full boot.
  • ShadowMountPlus 1.7beta4 : prerelease title registration; load kstuff first and complete app files before scanning.
  • FTP server v0.21.1 : keep its console endpoint on your trusted LAN.
  • Kernel log server v0.9 : optional troubleshooting.

These downloads are also available individually. The WebKit Autoloader installer adds an optional homescreen entry. You do not need to install it to use the hosted setup. The autoloader's default loader is console-only; cached entry and payload-file updates are separate operations.

Privacy

We count HTTP paths (without query strings), status, bytes and timing, plus aggregate DNS responses. Access logs do not record client IPs, cookies, user agents or DNS query histories. Operational errors may include connection details and are access-restricted. Raw logs are size-capped and rotate; private daily aggregates are kept for seven days. Counts indicate requests, not unique users or successful jailbreaks.
