Start Relapse

Keep system software updates off. Fully boot the console before starting. Open User's Guide after setting both DNS fields to 130.162.174.95. Relapse starts the loader, then the setup downloads and sends kernel logs, kstuff-lite, ShadowMountPlus and FTP. Return home when startup finishes.

Open Payload Manager, then Settings → Manage Sources → Add Source. Add https://exploit.myfl.uk/payloads.json. Select myfl.uk PS5 essentials to browse and download the pack. Choose payloads from the catalogue; Autoload controls which downloaded payloads start automatically.

Payloads and homescreen entry

Download the preconfigured autoloader payload folder. Extract ps5_autoloader to the USB root or /data/. Its autoload.txt loads logs, kstuff, ShadowMountPlus and FTP when you open the homescreen app after boot.

  • WebKit Autoloader installer v0.5.2 : send after the first jailbreak, then follow its installation/reboot instructions.
  • Payload Manager v0.5.2 : select payloads using its web interface.
  • kstuff-lite v1.11 : kernel patches for apps that require them, loaded after full boot.
  • ShadowMountPlus 1.7beta4 : prerelease title registration; load kstuff first and complete app files before scanning.
  • FTP server v0.21.1 : keep its console endpoint on your trusted LAN.
  • Kernel log server v0.9 : optional troubleshooting.

The files below are available to load as needed. The WebKit Autoloader installer adds an optional homescreen entry. You do not need to install it to use the hosted setup. The autoloader's default loader is console-only; cached entry and payload-file updates are separate operations.

DNS entry

In PS5 Settings → Network → Settings → Set Up Internet Connection, select your connected network and open Advanced Settings. Set DNS to Manual, then set both Primary and Secondary DNS to 130.162.174.95. Save and reconnect. Open Settings → User's Guide, Health and Safety, and Other Information → User's Guide.

This redirects both manual hostnames, blocks update.playstation.net and resolves other domains normally. A general public secondary resolver can bypass interception and blocking. If the internet test fails, try the guide directly; if it also fails, record its exact error and restore DNS to Automatic. Keep system software updates disabled.

Privacy

We count HTTP paths (without query strings), status, bytes and timing, plus aggregate DNS responses. Access logs do not record client IPs, cookies, user agents or DNS query histories. Operational errors may include connection details and are access-restricted. Raw logs are size-capped and rotate; private daily aggregates are kept for seven days. Counts indicate requests, not unique users or successful jailbreaks.
